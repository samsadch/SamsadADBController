Core Capabilities

Engineered for Humans & Autonomous Agents

From everyday IDE workflow shortcuts to autonomous multimodal agent debugging, everything is unified through a shared high-performance engine.

🤖

51-Tool AI Agent MCP Server

Give Google Antigravity, Claude Code, Cursor, and Windsurf full vision (multimodal screenshots), precise gestures (tap, swipe), SQLite querying, and memory profiling.

📝

Live SharedPreferences & DB Inspector

Inspect, add, modify, and delete SharedPreferences XML entries and SQLite table rows on-device in real-time with typed validation and zero data loss.

⚡

1-Click App Lifecycle & Permissions

Instant soft restart, clear cache/data, clean reinstall, and toggle runtime permissions (`CAMERA`, `LOCATION`, `NOTIFICATIONS`) dynamically.

🔋

Hardware & Power Simulator

Simulate critical battery levels (5%, 20%, 50%, 100%), AC unplugging (discharging state), and force deep Doze mode (`force-idle`) to verify background jobs.

📊

Non-blocking Logcat & Memory Telemetry

Stream filtered Logcat logs with PID/tag/severity filters without hanging, and parse full `dumpsys meminfo` heap and RSS breakdowns.

🚀

Deep Links & Intent Tester

Dispatch custom URI schemes, Android App Links, and broadcast intents with typed extra parameters in a single click.
